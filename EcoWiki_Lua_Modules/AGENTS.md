# AI Rules & Context: Wiki Project (Lua & JSON)

## 📌 Project Overview
Это проект Wiki, где контент и логика разделены:
- **Логика и шаблоны**: Написаны на языке **Lua** (модули для генерации разметки, парсинга и обработки данных).
- **Данные**: Хранятся в формате **JSON** (базы данных, справочники, статические структуры).

## 📂 Repository Structure
* `/Data/` — Справочники, переводы, конфигурации и статические данные в JSON.

## 🛠 Tech Stack & Requirements

### 1. Lua Guidelines
- **Версия**: Lua 5.1 / Luajit (стандарт для MediaWiki Scribunto). Не используйте фичи из Lua 5.2+.
- **Стиль кода**: 
  - Локальные переменные по умолчанию (`local foo = ...`). Избегайте загрязнения глобальной области.
  - **Безопасность**: Не используйте запрещенные в Wiki функции (`os`, `io`, `debug`, `require` для внешних системных библиотек), если это не запуск локального CLI-окружения.
  
### 2. JSON Guidelines
- **Валидность**: Только строгий JSON. Никаких trailing commas (запятых в конце списков/объектов), одинарных кавычек или комментариев.
- **Связи**: Если JSON ссылается на Lua-модуль (или наоборот), проверяйте точное совпадение ключей/имен.

## 🤖 AI Core Instructions (Rules)
1. **Не изменять JSON**
2. **При изменении Lua**:
	- При чтении JSON-файлов всегда используйте `mw.ext.data.get`, что бы получить данные из общей базы данных MediaWiki, но ссылка должна выноситься в отдельный Lua файл, чтобы задействовать кэширование.
	- Всегда проверяйте входящие аргументы на `nil` и пустые строки (`""`).
